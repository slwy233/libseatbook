长临时路径会使当前 Windows 环境中的 JDK 回环连接失败，构建时将 TEMP/TMP 设置为 C:\lsb\tmp，并通过 JAVA_OPTS 传入短临时路径。避免使用 JAVA_TOOL_OPTIONS 传递这些参数：其标准错误提示会被本版本 Android Prefab 工具当作原生库错误。最终执行的构建任务为：

~~~powershell
$env:TEMP = 'C:\lsb\tmp'
$env:TMP = 'C:\lsb\tmp'
$env:JAVA_OPTS = '-Djava.io.tmpdir=C:\lsb\tmp -Djdk.net.unixdomain.tmpdir=C:\lsb\tmp'
Remove-Item Env:JAVA_TOOL_OPTIONS -ErrorAction SilentlyContinue
.\gradlew.bat --no-daemon :app:assembleRelease -PreactNativeArchitectures=arm64-v8a
~~~

新环境需安装依赖并通过 Expo prebuild 生成原生工程；本命令从 android 目录执行。安装包和本地构建日志按 .gitignore 保留在 outputs，未提交到源码仓库。
