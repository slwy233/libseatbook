# 后端优化说明

本次在最新 Desktop 项目上修改，针对学校接口实测中出现的短间隔限流及后端启动、请求处理问题。

## 改动

- 学校请求独立为 school_client.py。认证请求从公开接口取得 HMAC 配置，默认缓存 15 分钟，到期重新获取；每次调用和重试生成新 nonce、时间戳和签名，不再使用源码中的静态 HMAC 密文。
- 空闲座位、布局查询按接口和 token 摘要控制间隔，默认 2 秒。只读请求明确收到“访问过于频繁”或 HTTP 429 时，等待至少 2 秒，只重试一次。这个默认间隔尚未在线验证为学校的限流阈值，可按运行结果调整。
- 只读查询遇到数字或字符串 20003 时，按该任务账号重登，并重试一次。新 token 写回本轮账号缓存，后续查询及预约使用更新后的会话。
- 预约和取消不在传输层自动重发；无法确认学校只读数据时跳过预约。网络超时后的预约结果仍由下一轮已有预约检查确认。
- 登录遇到明确的账号或密码拒绝立即结束；验证码及临时失败最多 5 次，并采用 2、4、8、8 秒退避。
- OCR 与调度共用 backend_runtime.py 中的输入校验、响应格式、图片解码与算式解析。模型第一次识别时才加载，并串行执行推理；OCR HTTP 使用独立请求线程，健康查询不被慢识别阻塞。
- OCR 请求限制为 2 MiB JSON、1 MiB 解码图片。无效 JSON、非对象、错误长度、错误 Content-Type、无效 base64、未知路由返回明确 4xx；模型异常返回去敏 503。除零算式和空识别结果不再作为有效验证码返回。
- 两个服务均支持 --host、--port。定时服务新增 --task-file 和 --no-scheduler；创建任务尊重 enabled:false。已有 API 正常响应结构、端口及单进程 JSON 原子存储方式保持兼容。

## 启动

在项目根目录安装后端依赖：

~~~sh
python -m pip install -r ocr_server/requirements.txt
python ocr_server/server.py --host 127.0.0.1 --port 8910
python ocr_server/schedule_server.py --host 127.0.0.1 --port 8911 --task-file ./local-tasks.json --no-scheduler
~~~

最后一条仅启动 API，不启动自动预约；本地调试请使用独立任务文件。正式运行时去掉 --no-scheduler，并显式指定已有任务文件，例如 /opt/schedule_tasks.json。

必须将 server.py、schedule_server.py、backend_runtime.py、school_client.py 放在同一目录；新版不再是复制单个 Python 文件即可部署。

| 环境变量 | 默认值 | 含义 |
|---|---|---|
| OCR_HOST / OCR_PORT | 0.0.0.0 / 8910 | OCR 监听 |
| SCHEDULE_HOST / SCHEDULE_PORT | 0.0.0.0 / 8911 | 定时服务监听 |
| SCHEDULE_TASK_FILE | 服务脚本目录中的 schedule_tasks.json | 任务文件 |
| SCHOOL_BASE_URL | https://libseat.tjcu.edu.cn/jsq | 学校入口 |
| SCHOOL_REQUEST_TIMEOUT | 15 | 请求超时，秒 |
| SCHOOL_CONFIG_TTL | 900 | 签名配置缓存，秒 |
| SCHOOL_QUERY_INTERVAL | 2 | 座位及布局查询间隔，秒 |

## 验证与边界

运行 python -m unittest discover -s tests -p "test_*.py"。测试包含原有任务存储、账号隔离、并发执行、现有预约保护回归，以及新增缓存刷新、签名字段、限流退避、过期重登、只读/写操作重试差异、OCR 请求校验与回环 HTTP 测试。学校请求使用离线响应，OCR 使用模拟模型；没有触发真实预约或取消。

2026-10-07 已更新 39.106.98.187 上的 OCR 与定时服务。服务器执行 56 项后端回归测试通过；真实 ddddocr 模型可初始化，学校公开签名配置获取成功，真实签名的未登录个人信息查询返回 20002。两个 systemd 服务均为 active，公网 8910/8911 的 /health 均返回 HTTP 200。现有任务文件内容保持不变，部署时任务数为 0；旧代码和服务配置保存在 /opt/libseatbook-backups/20261007-v1.0.1-1791385113076。未触发真实预约或取消，未验证识别准确率、已登录会话和在线限流恢复。

已有边界仍然适用：JSON 任务文件仅支持单进程；定时 API 的身份认证和任务归属权限尚未实现，现有客户端服务地址仍为 HTTP。这里不改变客户端协议或部署架构。
